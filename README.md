# 🛠 Jonas Daniel | Portfolio

> Portfólio profissional interativo, desenvolvido para apresentar minha trajetória, habilidades e projetos como desenvolvedor.

🔗 **Live Demo**: [portifolio-2ctd.vercel.app](https://portifolio-2ctd.vercel.app)

---

## 📖 Sobre o Projeto

Este é o meu portfólio pessoal, construído do zero com foco em performance, responsividade e uma experiência visual moderna. O site apresenta quem eu sou, minhas principais habilidades técnicas e uma seleção dos meus projetos mais relevantes.

---

## ✨ Funcionalidades

- 🎨 Design moderno com animações suaves ao rolar a página (*reveal on scroll*)
- 📱 Totalmente responsivo (desktop, tablet e mobile)
- 🧭 Navegação por âncoras com menu hambúrguer para mobile
- 📊 Barras de progresso animadas para exibir nível de habilidade
- 🗂️ Seção de projetos em destaque, com links para código e demonstração
- 📬 Seção de contato direta, com e-mail e redes sociais

## 📂 Estrutura do Projeto

```
📦 portfolio
 ┣ 📂 src
 ┃ ┣ 📂 images     → Ícones e imagens usadas no site
 ┃ ┣ 📂 styles     → Arquivo de estilização (style.css)
 ┃ ┗ 📂 scripts    → Script de interações (script.js)
 ┣ 📜 index.html   → Estrutura principal do portfólio
 ┗ 📜 README.md
```

## 🚀 Como Rodar Localmente

```bash
# Clone este repositório

# Acesse a pasta do projeto

# Abra o arquivo index.html diretamente no navegador
```
